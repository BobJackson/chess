# 《松风桂月》整体玩法设计

> 松风起，桂子落，来一盘。

## 一、产品定位

一款**为两个人而下**的中国象棋微信小游戏：松树与桂花的专属棋枰。
熟人娱乐导向——无赌注、无积分、无排位，胜负只关风月，不关利益（同时满足「休闲」类目合规口径）。

- **平台**：微信小游戏（整屏 Canvas 自绘 UI）
- **气质**：木质宣纸、国风描金；落子有声，BGM 可开关
- **合规边界**：无虚拟币、无输赢结算、无提现诱导、无陌生人匹配

## 二、核心玩法循环

```
选模式 → 开局对弈 → 终局判定 → 复盘情绪（悔棋/重开/分享）→ 再来一局
```

单局时长预期：人机 5–15 分钟；双人对局 10–30 分钟（联机长连接超时 60 分钟，足够一盘慢棋）。

## 三、三大对局模式

### 3.1 人机对战 ✅

与 AI 对弈，执红先行（人类方），五档难度覆盖从第一次摸到棋子到业余高手：

| 档位 | 搜索深度 | 风格设定 | 适合谁 |
|---|---|---|---|
| 入门 | 2 层 | 有明显失误、走法随机大 | 零基础，先体验吃子的快乐 |
| 简单 | 3 层 | 偶尔失误、带开局库 | 懂规则的新手 |
| 中等 | 4 层 | 无失误、正常发挥 | 日常对弈主力档（默认） |
| 困难 | 6 层 | 无失误、开局变化少而精 | 有棋力的爱好者 |
| 大师 | 8 层 | 最强算力 | 想被虐的时候 |

入口：主菜单「人机对战」，难度在主菜单分段选择，开局前可见。

### 3.2 本地双人 ✅

同一台手机轮流走子，适合饭后沙发上、旅途中面对面来一盘。
无账号、无网络要求，即点即玩。

### 3.3 好友联机 ✅

远方的 TA，一张卡片开局：

1. 房主点「好友联机 → 创建房间」，得到 **4 位房间号**（房主执红）；
2. 点「邀请好友」或右上角菜单「发送给朋友」，分享卡片自带房间号；
3. 好友点开卡片 → 自动进入大厅 → 自动加入房间 → 双方直接进入对局；
4. 走子实时同步；任一方退出，对局结束并通知对方；房主退出自动清理空房间。

联机通道双实现：自建 WebSocket 中继（wss）/ 微信云开发，配置切换。

## 四、对局内交互

### 4.1 走子与规则 ✅

- 完整中国象棋规则：兵种走法、蹩马腿、塞象眼、将帅不照面等全部生效；
- **将军提示**；**将死与困毙均判负**；支持认输、对手退出判负；
- **新手引导提示**（2026-09-26）：选中一枚动弹不得的子时即刻解释原因——被牵制「移动将送将（帅）」（红帅黑将分称）、正被将军时「此子无法解将」、被围死「此子暂无去路」；尝试走出送将的棋（点选或拖拽落点）同样提示对应文案，纯无效点则静默取消不打扰；
- 中文记谱（着法记录），复盘回放的数据基础（见 4.4）。

### 4.2 工具栏五键 ✅

| 按钮 | 人机/本地 | 联机 |
|---|---|---|
| 悔棋 | ✅ 可悔 | ❌ 禁用（公平原则） |
| 提示 | ✅ AI 支招 | ✅ |
| 翻转 | ✅ 换视角 | ✅ |
| 重开 | ✅ | ❌ 禁用 |
| 菜单 | 返回主菜单 | 退出并通知对手 |

### 4.3 氛围 ✅

- 全局 BGM（双曲目《松风》《桂月》自由切换）+ 走子/吃子/将军音效；
- 设置页统一管理：音乐/配乐/音效/先后手，选择持久化；
- iOS 首次触摸后启动音乐（符合平台自动播放限制）。

### 4.4 复盘回放 ✅（2026-09-26）

- 终局落款新增「复盘」按钮（联机也有），进入独立复盘场景；
- 从开局按记谱逐手重放：开局 ⏮ / 上步 ◀ / 播放·暂停 / 下步 ▶ / 退出，
  前进带走子动画与音效，自动播放 900ms 一手、播到终局自停；
- 状态栏实时显示「第 x/n 手 · 着法」；棋盘不吃触摸，视角沿用对局结束时的翻转；
- 停在终局且有杀法时中键变「绝杀」，复用绝杀演出再演一遍（点屏收起）。

### 4.5 系统设置页 ✅（2026-09-26）

- 主菜单只留一个「系统设置」入口（查看规则之下），不为每个选项加按钮；
- 行式分段控件：音乐开关 / 配乐（松风·桂月）/ 音效开关 / 先后手（执红·让先执黑）；
- 新增设置项只需在设置页 ROWS 加一行，菜单永不再动。

## 五、界面流转

```
主菜单（标题/难度/模式入口/系统设置）
 ├─ 人机对战 ─→ 对局
 ├─ 本地双人 ─→ 对局
 ├─ 好友联机 ─→ 大厅（创建/加入/邀请）─→ 对局
 ├─ 查看规则 ─→ 规则页（兵种走法+胜负判定，可滚动）
 └─ 系统设置 ─→ 设置页（音乐/配乐/音效/先后手）
对局终局 ─→ 绝杀演出 ─→ 复盘（逐手回放）─→ 主菜单
分享卡片回流 ─→ 大厅自动填入房间号并加入
```

## 六、🆕 本期扩展建议（待确认）

### 6.1 ✅ 松桂账本（2026-09-25 已实现）

二人专属胜负记录：本机持久化（`wx.setStorageSync`）记录"松 vs 桂"的历史战绩——总局数、各自胜场、最近一局时间与结果，主菜单展示一行："松 12 : 9 桂"。

已实现口径：
- 只记人对人的局：**本地双人**（红=松、黑=桂）与**好友联机**（本机=松、对方=桂）；人机是练棋，不入账；
- 和棋单独计数；主菜单同时展示最近一局（"上局 桂胜 · 联机 · 09-22"）；
- 实现在 `core/ledger.js`（纯 JS + 注入式存储适配器），终局时由对局场景记账，每局一次。

另：**AI 卡顿已同步解决**（2026-09-25）——搜索改为分片调度（每片 12ms 让出主线程），大师档不再冻屏，"提示"按钮同样走分片。

**账本详情页**（2026-09-26）：主菜单比分行可点进入——大比分 + 当前连胜（≥2 连胜、和棋断连）
+ 逐局历史（日期/模式/胜负 + 结果文案，最新在上，可滚动）；逐局记录存最近 50 局。

### 6.2 ✅ 先后手选择（2026-09-26 已实现，设置页入口）；让子（🟠 中，待做）

开局前可选执红/执黑（让先）：设置页「先后手」分段，默认执红，人机/本地生效；
人机执黑时 AI 执红自动先走，本地双人执黑时账本按松的边记。联机维持房主执红（协议不动）。
